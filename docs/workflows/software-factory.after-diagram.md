## Status: target state

The graph specifies the resident operating model. The dashboard can install its
agent bundle in your account or organization `.agents` repository, but it does
not deploy or operate the resident runtime. Public resident packaging and
managed execution remain in development.

For a workflow you can run now, use the [local engineer workflow](/workflows/engineer/).
For a no-configuration trial, [delegate one hosted issue](/docs/cloud/); that
one-shot service is not the resident workflow shown here.
