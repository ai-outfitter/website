## From setup to shipping.

Set up a personal or organization `.agents` repository with our GitHub App or
configure it yourself. Adopt a workflow to give your agents shared context,
skills, and instructions, then put them to work across your team.

## Outfit once. Work everywhere.

Keep agent context, skills, tools, and permissions in a reviewable `.agents/`
tree. Give one person an agent team—or roll it out across your organization.

<div class="signal-grid">
  <div>
    <span class="number">01 / OUTFIT</span>

  <div>

### Publish once. Delegate from every harness.

An admin publishes the organization’s shared agent context once. A non-admin
employee syncs it, then Pi and Claude Code receive the same delegation prompt:
turn bounded work into a durable issue and let issue triage assign it to a
resident agent. Managed resident deployment and hosted inference are planned
capabilities; the dashboard labels them as planned rather than available.

[Follow the handoff through issue triage and the software factory →](/workflows/issue-triage/)

## Climb without rebuilding

Start with one delegated task. Share the configuration that worked. Move it to
an automated surface. Add governance and durable evidence when the system earns
more authority. Each rung keeps the useful parts of the last.

## Bring your harness. Keep your configuration.

Outfitter does not invent a private configuration format. The `.agents/`
directory remains useful on its own and can target Pi, Claude Code, Codex, and
the execution surfaces your organization already operates.

```sh
npx @ai-outfitter/outfitter
```
