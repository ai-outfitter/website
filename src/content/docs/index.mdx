<p class="eyebrow">Agentic workflows</p>

## Assign an issue. Get a reviewed pull request.

Install the GitHub App, choose inference, press Provision. The App becomes
your organization's resident agent, hosted by us. Label an issue and it
implements, reviews itself adversarially in a fresh conversation, and merges on
approve. Nothing is added to your repository — your first pull request is the
feature.

## Move the control point outward

AI Outfitter is an open toolchain for the part after “try a coding agent.” Keep
agent context, skills, tools, and permissions in a reviewable `.agents/` tree,
then reuse the same composition wherever the work runs.

### Publish once. Delegate from every harness.

An admin publishes the organization’s shared agent context once. A non-admin
employee syncs it, then Pi and Claude Code receive the same delegation prompt:
turn bounded work into a durable issue and let issue triage route it to a
deployed resident or the AI Outfitter GitHub App.

## Climb without rebuilding

Start with one delegated task. Share the configuration that worked. Move it to
an automated surface. Add governance and durable evidence when the system earns
more authority. Each rung keeps the useful parts of the last.

## Bring your harness. Keep your configuration.

Outfitter does not invent a private configuration format. The `.agents/`
directory remains useful on its own and can target Pi, Claude Code, Codex, and
the execution surfaces your organization already operates.

```sh
npx @ai-outfitter/outfitter
```
