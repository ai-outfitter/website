<p class="eyebrow">One shared operating model</p>

## From setup to shipping

Keep the context your agents need in a reviewable `.agents` repository. Adopt a
workflow, use it with the tools your team already has, and evolve the same
configuration as your agents earn more responsibility.

<div class="signal-grid">
  <div>
    <span class="number">01 / CONFIGURE</span>
    <h3>Create shared configuration</h3>
    <p>Put agents, skills, sources, and defaults in a repository your team can inspect and review.</p>
  </div>
  <div>
    <span class="number">02 / ADOPT</span>
    <h3>Accept a workflow</h3>
    <p>Start with the software factory or choose another workflow from the community catalog.</p>
  </div>
  <div>
    <span class="number">03 / RUN</span>
    <h3>Work where you already work</h3>
    <p>Use Pi, Claude Code, Codex, CI, or infrastructure your organization operates.</p>
  </div>
</div>

## Add autonomy without starting over

Start with one delegated task, then move the control point outward. Each layer
keeps the inspectable configuration and evidence from the last.
