---
title: Move the control point outward
description: The Outfitter adoption ramp moves from assisted coding to an autonomous lifecycle one evidence-backed boundary at a time.
---

The ramp is a sequence of control boundaries. Each rung changes who initiates
work, where it runs, and what evidence exists to review it.

| Rung | Operating model | Human control point |
| --- | --- | --- |
| Assisted | Autocomplete and chat support a person actively coding. | Every edit and decision. |
| Delegated | A local agent completes a bounded task and proposes a change. | Define the task and review the result. |
| Automated | Events or schedules run an agent without the laptop. | Define triggers, permissions, and acceptance gates. |
| Governed | Shared catalogs, policy, identities, and evidence bound agent work. | Set organizational policy and approve exceptions. |
| Self-improving | Evidence feeds evaluations and controlled improvement loops. | Set goals and approve promotion gates. |

Two rules keep the climb honest:

1. Automate nothing you have not first done manually.
2. Move the human locus of control outward one layer at a time.
