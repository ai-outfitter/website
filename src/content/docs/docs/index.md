AI Outfitter is a set of composable projects, not one monolith. Start with
[Outfitter](/docs/outfitter/getting-started/) to make agent configuration reviewable and
portable, then add the execution, communication, quality, and evidence pieces
your next adoption rung requires.

## Paths through the docs

- **New to AI Outfitter:** follow [Getting started](/docs/outfitter/getting-started/).
- **Choosing components:** use the [Project guide](/docs/projects/).
- **Designing an adoption plan:** read [Move the control point outward](/docs/outfitter/adoption-ramp/).
- **Understanding composition:** read [The `.agents` convention](/docs/outfitter/dotagents/).
- **Evaluating production boundaries:** read [Outfitter architecture](/docs/outfitter/architecture/).

Project pages here explain how the pieces relate. Commands and release-specific
reference remain canonical in each linked repository.
