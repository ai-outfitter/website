---
title: Autoimprove
description: Explore recursive, evaluation-driven improvement of portable Markdown skills.
---

Autoimprove implements a SkillOpt-style training loop for portable Markdown
skills. It explores candidate changes, evaluates them against a defined task
set, and uses results to guide the next iteration.

Use improvement loops only after the evaluation captures the behavior you
actually value. Optimization faithfully exploits a weak gate too.

- [Current usage and status](https://github.com/ai-outfitter/autoimprove#readme)
