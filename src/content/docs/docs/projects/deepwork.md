---
title: Deepwork
description: Define structured, multi-step agent jobs with typed inputs and quality gates.
---

Deepwork turns an open-ended request into a named job with explicit steps,
arguments, and checks. It is useful when the process matters as much as the
final answer: research, release preparation, investigations, and other work
that should prove each stage before moving on.

The package targets Pi, Claude Code, and Codex so a workflow definition can
travel with the work rather than one harness.

- [Repository](https://github.com/ai-outfitter/deepwork)
- [Package documentation](https://github.com/ai-outfitter/deepwork#readme)
