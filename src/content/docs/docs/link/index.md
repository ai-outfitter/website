---
title: Link
description: Audit organizations against measurable agentic SDLC signals and return a ranked next-step plan.
---

Link is a deterministic, read-only scanner for repository trees and effective
forge rules. It evaluates measurable signals in the Outfitter SDLC baseline and
returns a ranked plan for reaching the next adoption rung.

Link does not call a model and does not pretend local-only practice is visible
to a forge scan. Reports record their evidence limits, and missing evidence is
reported as unknown rather than turned into a negative claim.

```sh
npx @ai-outfitter/link report
```
