---
title: Outfitter
description: Resolve, compose, and launch reviewable agent configurations across supported harnesses.
---

Outfitter is the toolchain for `.agents`: it resolves configuration from local
and remote trees, composes agents, skills, and knowledge by slug, and launches
the result through wrapped agent CLIs.

```sh
npx @ai-outfitter/outfitter
```

Use Outfitter when configuration is drifting between tools, people, or
machines; when a shared skill should become everyone's pinned default; or when
the same profile needs to run locally and on an automated surface.
