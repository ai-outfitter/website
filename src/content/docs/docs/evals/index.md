---
title: Evals
description: Run reproducible, attested benchmarks for agent profiles, models, and workflows.
---

Evals provides declarative, container-based evaluations for the things that
actually change agent behavior: model selection, profile content, tools,
permissions, and workflow design.

Use it before promoting a configuration change beyond a small manual loop. A
repeatable evaluation makes “better” a result that can be compared and reviewed
instead of a remembered impression.

- [Repository](https://github.com/ai-outfitter/evals)
- [Current documentation](https://github.com/ai-outfitter/evals#readme)
