---
title: Extension packages
description: Focused Pi extensions for task structure, file collaboration, and shell recovery.
---

AI Outfitter publishes focused extensions that can compose into a profile
without turning the core toolchain into a monolith.

## Ulta Tasklist

[`ulta-tasklist`](https://github.com/ai-outfitter/ulta-tasklist) adds task-list
behavior for structuring and tracking agent work.

## File Talk

[`file-talk`](https://github.com/ai-outfitter/file-talk) gives selected files a
persistent semantic maintainer. A file-specific subprocess applies changes and
records durable context and rationale beside the file.

## Bash Saver

[`bash-saver`](https://github.com/ai-outfitter/bash-saver) can recover quick
shell failures through a constrained inner agent while preserving transparent
failure and recovery output.

These packages evolve independently. Read each repository's installation and
status notes before pinning it into a catalog.
